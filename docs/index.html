What is this?

qrvid turns arbitrary data — a document, a configured chatbot conversation, a complete HTML page, a saved game state, a multi-language manual — into a looping animated GIF made of QR codes. A camera reassembles the payload one frame at a time. The GIF loops forever, so missed frames are caught on the next pass: self-healing, with no protocol machinery.

A standard QR code holds about 3 KB. That covers a URL. It doesn't cover a document. qrvid breaks the payload into chunks, plays them back as a GIF, and your phone puts them back together. There is no server in the loop. No expiring link. No account. No app store.

Where it shines

  • Pre-filled web apps and forms — no link required
  • E-ink packaging, smart labels, kiosks
  • Offline-first content delivery at venues
  • Air-gapped data transfer through visible light
  • Digital signage that hands data to passers-by
  • Configured chatbot conversations, save states
  • Complete HTML apps delivered through a screen
  • Multi-language manuals from a single label

Origin

Built on top of smokesignal

qrvid extends jcomeauictx/smokesignal, an experiment in bidirectional QR-code data transfer between two devices facing each other. smokesignal proved the physical concept — visible light as a permissionless data channel — and qrvid takes the same idea and ships it as a one-way, asynchronous, broadcast-friendly GIF that plays on any screen, including printed paper and e-ink.
